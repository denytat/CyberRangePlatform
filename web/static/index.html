    Your mission: Find the hidden flag and submit it.

    Flag format: CR{...random_characters...} (example: CR{a1b2c3d4})

    Flag location hint: The flag is stored in a file on this container. Try: cat /flag.txt

    Useful commands:

    • find / -name "*flag*" 2>/dev/null
    • grep -r "CR{" / 2>/dev/null
    • env | grep -i flag
    • cat /flag.txt /root/flag.txt /tmp/flag.txt

    Type cat /etc/motd in the terminal to see instructions again.
